## Clash Verge Widget for macOS — first public beta

This is the first packaged release of the native, draggable Clash Verge Rev desktop widget for macOS.

### Included

- Live upload/download rates, cumulative traffic, and active connection count
- Direct Rule, Global, and Direct mode switching
- Direct System Proxy and TUN toggles
- Real post-action state verification
- Hidden-window control through Clash Verge's own React/Tauri UI callbacks
- Persistent desktop position and per-user automatic startup
- English and Simplified Chinese documentation

### Install

1. Download `Clash-Verge-Widget-v0.1.0-beta.1-macOS-arm64.zip` and extract it.
2. Run `Install.command` from Terminal.
3. Enable **Clash Verge Widget** in **System Settings → Privacy & Security → Accessibility**.
4. Open the Clash Verge main window once to initialize the accessibility connection. It can then remain hidden.

This build is ad-hoc signed and is not Apple-notarized. Verify the included SHA-256 checksum and download only from this repository. If macOS blocks the first launch, try opening the installed app once, then go to **System Settings → Privacy & Security** and choose **Open Anyway**. Run `Install.command` again afterward if automatic startup did not initialize. Do not disable Gatekeeper globally. See [Apple's safety guidance](https://support.apple.com/en-sg/102445).

### Compatibility

- macOS 14 or later
- Apple Silicon (`arm64`)
- Tested with Clash Verge Rev 2.5.10

### Known limitation

After Clash Verge, the widget host, or the embedded WebView restarts, open the Clash Verge main window once to rebuild the cached accessibility connection.
